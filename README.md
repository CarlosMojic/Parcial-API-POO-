# API para Tienda de Alquiler de Juegos

Esta API permite gestionar productos de una tienda de videojuegos. Fue desarrollada con Java y SpringBoot.

## Tecnologías utilizadas

- Java 17
- Spring Boot
- Maven
- Postman (para pruebas)
- Git y GitHub
